### 📱 Schnellanleitung für das iPad
1. Öffne die **[Hauptpräsentation](https://madaimbot.github.io/p-seminar-unternehmer/)** in Safari auf deinem iPad.
2. Tippe oben auf das **Teilen-Symbol** (Viereck mit Pfeil nach oben) und wähle **„Zum Home-Bildschirm“**.
3. Starte die Präsentation über das neue Homescreen-Icon – sie öffnet sich automatisch im **rahmenlosen echten Vollbild** ohne Browserleiste!
4. **Steuerung:**
   * **Wischen:** Nach links wischen = Nächster Beat / Nach rechts = Zurück.
   * **Rand-Tap:** Rechter Rand = Vor / Linker Rand = Zurück.
   * **Zoom:** Beliebige Kachel antippen = Direkter Spotlight-Zoom.
   * **Notizen:** Menü unten rechts -> *Notizen (N)* öffnet dein Sprecher-Overlay.
